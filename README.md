# Протокол — прототип СЭД

React 19, TypeScript, Vinext / Vite. Однопользовательское приложение на русском языке.

## Запуск

Требуется Node.js 22.13 или новее.

```sh
npm ci
npm run dev
```

Откройте адрес, напечатанный сервером. Для записи нужен микрофон и разрешение браузера; работает на HTTPS и localhost.

## Запуск frontend и backend через Docker

Для полного локального стека нужен Docker с Compose v2. Перед первым запуском
примите условия модели `pyannote/speaker-diarization-community-1` в Hugging Face,
создайте read-токен и выполните:

```sh
cp backend/.env.example backend/.env
# Впишите HF_TOKEN и адрес Ollama на другом ПК в backend/.env:
# OLLAMA_URL=http://192.168.1.100:11434
docker compose --env-file backend/.env up --build -d
```

Frontend: <http://localhost:5173>. Swagger API: <http://localhost:8000/docs>.
Первый запуск скачивает несколько гигабайт моделей и занимает больше времени.
Локальный контейнер Ollama по умолчанию не запускается. Удалённая Ollama должна
слушать LAN-интерфейс, а порт 11434 должен быть доступен с этого компьютера.

Проверка состояния и просмотр логов:

```sh
docker compose --env-file backend/.env ps
docker compose --env-file backend/.env logs -f bootstrap ollama-init api worker frontend
```

Остановка с сохранением базы, записей и моделей:

```sh
docker compose --env-file backend/.env down
```

## Возможности

- Создание совещаний с участниками, подразделениями и повесткой.
- Запись через MediaRecorder, таймер, прослушивание и скачивание аудио.
- Демонстрационная расшифровка и формирование проекта по повестке.
- Редактирование вопросов, решений и всех полей поручений.
- Утверждение с проверкой полей и защитой от повторного создания поручений.
- Просмотр и печать утверждённого протокола.
- Статусы, фильтры, расчёт просрочки и внутренние уведомления.
- Сохранение документов и аудио в IndexedDB; восстановление демоданных сохраняет созданные пользователем встречи.

## Архитектура

`lib/types.ts` — Meeting, Participant, TranscriptSegment, Protocol, Assignment.
`lib/domain.ts` — утверждение, валидация и календарные сроки.
`lib/storage.ts` — атомарное сохранение рабочего пространства в IndexedDB.
`lib/demo-recognition.ts` — отдельный демонстрационный сервис для замены реальным API.
`app/` — интерфейс, запись, создание встречи и редактор протокола.

Протокол после утверждения неизменяем; статусы исполнения хранятся в реестре поручений. Просрочка определяется по локальной календарной дате, начиная со следующего дня после срока. Выполненные поручения не становятся просроченными. Уведомления включают просроченные поручения и сроки не позднее трёх дней от текущей даты.

## Ограничения прототипа

Распознавание и ИИ демонстрационные: аудио не анализируется и никуда не отправляется. Нет серверной авторизации, синхронизации между браузерами, почтовых уведомлений и интеграции с внешней СЭД. Публикация Sites может требовать вход владельца на уровне хостинга. Данные привязаны к адресу сайта и браузеру: локальный предпросмотр и опубликованный сайт имеют независимые базы. Очистка данных сайта удалит документы и аудио. Рекомендуется работать в одной вкладке.

WebMCP предоставляет read-only инструмент `list_meeting_assignments`; неподдерживаемые браузеры продолжают работать без него.
