# Проверка реализации

Дата: 23 сентября 2026. Среда: Windows, Python 3.12.14, PostgreSQL 17.

## Выполнено

- Полный набор pytest на отдельном PostgreSQL: **78 passed**. Для каждого теста используется собственная временная схема; существующие пользовательские базы не изменялись.
- Проверены API загрузки, участников, speaker mapping, анализа, изменения и фильтрации поручений, DOCX/PDF, ошибки валидации, привязки между разными встречами и общий API-key.
- Проверены долговечная очередь, запрет дублирующихся активных заданий, конкурентный `SKIP LOCKED`, heartbeat, восстановление истёкшего lease, защита от устаревшего worker и предел попыток восстановления.
- Проверены максимальное суммарное temporal overlap, UNKNOWN, mixed-language параметры Whisper, локальная загрузка моделей, schema Ollama, цитаты-основания, неподтверждённые имена, сроки RU/KK и сохранение ручных правок при повторном анализе.
- На реальном PostgreSQL успешно выполнены `alembic upgrade head`, `alembic check`, `alembic downgrade base`, повторный `upgrade head` и `check`. Изменений схемы относительно ORM не обнаружено.
- Запущен отдельный Uvicorn HTTP-процесс и проверены `/health/ready`, авторизация, список встреч, Swagger и OpenAPI. Проверка завершает свой процесс самостоятельно; рабочий сервер не оставлен запущенным.
- Реальный FFmpeg 7.1 преобразовал синтетические WAV, MP3, M4A, MP4 и WebM в mono, 16 kHz, PCM 16-bit. Измерены параметры выходного WAV. В этих тестах FFprobe подменён: пакет `imageio-ffmpeg` содержит только FFmpeg. Обработка ошибок FFprobe покрыта отдельно с подменой subprocess.
- DOCX прочитан обратно через python-docx; PDF — через pypdf. Проверены русский текст, казахские буквы `Ә Ғ Қ Ң Ө Ұ Ү Һ І`, имена, цитаты и экранирование разметки.
- Синтетический PDF отрендерен Poppler и визуально проверен: текст помещается, заголовки и интервалы читаемы, казахские символы отображаются. Образцы в локальном игнорируемом каталоге `verification/`.
- Linux/Python 3.12 зависимости из `requirements-ai.txt` успешно разрешены через `uv pip compile` без скачивания весов. Это проверка совместимости требований, а не запуск моделей.
- Ruff lint/format, компиляция Python и `pip check` — пройдены.
- Проверена структура Compose: рабочие сервисы находятся в изолированной сети, initialization-сервисы не имеют доступа к volume записей, HF token отсутствует в окружении рабочих сервисов.

## Не проверено в этой среде

- **Сборка и запуск Docker Compose:** Docker не найден. YAML и сетевые настройки проверены тестами, но это не замена реальному контейнерному запуску.
- **Whisper large-v3, pyannote community-1 и Qwen3:8b на настоящей записи:** веса не скачивались; доступ к gated pyannote требует принятия условий и токена пользователя. Pipeline-тесты используют подставные результаты моделей.
- **GPU:** CUDA-конфигурация подготовлена, но инференс на NVIDIA GPU не выполнялся.
- **Качество распознавания и diarization:** WER/DER и качество извлечения поручений на пользовательской русско-казахской речи не измерены. Для приёмки нужен размеченный набор реальных записей.
- **Визуальный рендер DOCX в Word/LibreOffice:** проверены содержимое и структура файла; полноценного визуального рендера DOCX в этой среде не было.

## Воспроизведение

Из каталога `backend`, после установки `requirements-dev.txt`:

```powershell
$env:TEST_DATABASE_URL = 'postgresql+asyncpg://user:password@localhost:5432/meetings_test'
python -m pytest -q
python -m ruff check app tests scripts alembic
python -m ruff format --check app tests scripts alembic
python -m pip check
```

Для миграций и HTTP smoke задайте `DATABASE_URL` на отдельную тестовую БД, выполните `alembic upgrade head`, затем `python scripts/smoke_http.py`.

Без `TEST_DATABASE_URL` pytest использует SQLite; тест PostgreSQL-конкурентности пропускается. Ни один стандартный тест не требует записи пользователя, HF token или доступа к облачным AI API.
